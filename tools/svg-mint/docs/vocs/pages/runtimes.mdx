# Runtimes

The desk runs on groot2. Zakura is a Docker archive, not a second copy of the submodule checkout. The fed binary is native x86_64, built with the host stable compiler because `rust-toolchain.toml` pins 1.86 and `zcash_address` 0.13 needs 1.88.

| Process | Bind | State on the house |
|---|---|---|
| `zakura-lab` `zakuracore/zakura:1.7.0` | `127.0.0.1:8232` cookie JSON-RPC | Archive, format 30, not pruned. Do not reopen this directory with 1.6.0. |
| `lwd-lab` `lightwalletd:v0.5.3` | `127.0.0.1:9067` | Live compact server. The mint curator does not dial it. |
| ztreamer | intended `127.0.0.1:9067` | Not running. Do not start a second compact server until scan is linked. |
| `svg-mint-fed` | `127.0.0.1:8421` | User unit `dregg-svg-mint-fed.service`. Store `~/.terp/svg-mint-fed-cell.json`. The binary default bind is loopback. |
| `svg-mint-zrt` | no port | Binary not installed. Do not `init` `~/.terp/svg-mint-zrt`. |
| HashMerchant `onboard-runtime` | `127.0.0.1:19090` | Unit present, inactive. Keyring dir `~/.terp/kr-onboard` is absent. The fed's embedded listener must not take this port. |

ETH, Base, and BTC watcher threads stay in the fed. Their RPC variables stay unset.

## Git pins

Submodule pins in the product tree are still Zakura `v1.6.0` and ztreamer. The running node is the 1.7.0 image. Do not move the pin until a release commit says so. Do not point 1.6.0 at the format-30 archive.

```bash
bash scripts/init-runtimes.sh
```

That clones the submodules. It does not start the house containers.
