# Zakura

Zakura is the house Zcash full node, currently `zakurad` 1.6.0. RPC is loopback only. The browser never calls it.

DREGG compares house `getblockcount` to a public tip (max drift 2) before offering a `zec_uri`. Drift hides ZEC Pay; native THIOL can stay open.

There is no paid Akash porch in the current cut. The node dials public mainnet seeds. P2P is not published on the house WAN.

See [Runtimes](/engines/runtimes) for the git submodule pin.
