# ztreamer

ztreamer is the compact server the product spec names. `GetLightdInfo.vendor` must be `Ztreamer`. The fed's `ztreamer probe` fail-closes the zrt note watch when `ZTREAMER_GRPC` and `ZTREAMER_BIN` are both set and the vendor is not Ztreamer.

What is bound on the house today is `lwd-lab` (`electriccoinco/lightwalletd:v0.5.3`) at `127.0.0.1:9067`. The mint curator does not open that port. It trusts `mined` inside `svg-mint-zrt notes` JSON. `sync` on this zrt build does not dial a compact server, so neither lightwalletd nor ztreamer can see a payment until scan is linked.

Do not start a second compact server. Do not publish `:9067`. Do not point compact clients at zec.rocks or rotko.

Lab bind, when a ztreamer is actually started, is `127.0.0.1:19067`. House bind is `127.0.0.1:9067`, which means replacing `lwd-lab` only after scan is linked and the vendor probe passes.
