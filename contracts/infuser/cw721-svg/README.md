# Cw721-SVG

This contract creates svg metadata that can interact & mutate with on-chain data.

## GOALS

- provide inital svg, with pre-determined variables set inside parameters`${}`
- use token-id + inital random seed + block height to generate entropy to determine values for variables

- queries are optimized:
  - default nft query to contained token-id params (expect front ends to know svg in use already)
  - backup query for full svg with tokenized params
- minter & contract in singleton contract, instantiate function acts as launchpad

- max limit svg
